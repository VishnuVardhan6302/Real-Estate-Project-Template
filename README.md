# Leah Bennett — Luxury Real Estate Website

A responsive, single-page React + Vite recreation based on the eight Canva screenshots provided.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Customize
- Edit `src/App.jsx` to change text, property listings, contact details, and social links.
- Replace images in `src/assets/` with the original high-resolution Canva photos if available.
- Update the contact form submit handler to connect a backend or form service. It currently displays a local success message only.
- Replace the video tour preview modal with your actual video embed or URL.

## Build for deployment
```bash
npm run build
npm run preview
```
